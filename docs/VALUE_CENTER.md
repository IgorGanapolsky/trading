## Shift

| From                     | To                                       |
| ------------------------ | ---------------------------------------- |
| Autonomous product teams | **Agency + coherence**                   |
| “Our product” theater    | **Value center** (why this lane exists)  |

## Five questions (every tick / every lane)

1. **What value am I delivering?**
2. **How do we coordinate?**
3. **How do we fit together?**
4. **What's out there for us?**
5. **Who are we?**

Run: `python3 scripts/value_center_status.py`

## Molecule metaphor (Rohrer)

- **Simple molecules:** standalone tools (Stripe checkout, dial card) — few deps.
- **Complex molecule:** “make money” only when dials → fee-yes → Stripe non-owner clear. You can decouple _code_ deploy; you cannot decouple _value_.

## Fail-closed

Overall A+/“profitable” while `cash_fee_yes` unmet = **coherence failure** (autonomy theater).
