# Bogleheads Research Skill

Extracts real-time discussions, asset allocation recommendations, and index investing insights from Bogleheads.org.

## Features
- **RSS Feed Extractor**: Runs `python3 scripts/bogleheads_research.py` to extract the latest 15 discussions.
- **Secure Credentials**: Credentials stored securely in `~/.resume_secrets/bogleheads.json` (`chmod 0600`).
- **Safety Policy Compliance**: Does not violate Rule 0 (Browser Session Safety Lock) or perform automated browser logins / unauthorized posting.
